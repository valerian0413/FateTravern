FateTravern
GUIDE / 使用说明

先知道这是什么，再开始冒险

FateTravern 是跑在你自己电脑上的单人跑团。主持人由大模型担任，你用自然语言玩。

先体验一场现成的冒险

演示里已经写好世界和角色。开始后会复制一份新存档，原来的演示不会被改掉。

它在做什么

  • 创建世界时，把背景、超凡、货币、交通等收成一份可以修改的设定表。你确认之后，这些内容才写入存档。
  • 创建角色时使用简化的 Fate：两个形象（高概念、自由形象），十九项技能里一个 +2、两个 +1，一条压力轨（1 / 2 / 3），以及轻微、中度、严重伤痕（2 / 4 / 6）。退让可获得命运点。初始没有绝技。
  • 进入冒险后有两个窗口。「旅途见闻」只显示已经发生的行动和世界的直接回应。另一边用来和主持人说话：问规则、商量计划，或声明行动。
  • 讨论只用来问规则和商量计划。游戏时间在你声明行动之后才前进，也只有行动才可能掷骰。
  • 你临时提出的新设定会先经过审核。和已有设定冲突时，主持人给出修改建议，你点头之后才写进世界。

怎样写提示词

一句短话就够。你负责决定要什么，主持人负责把场面和设定补全。含糊的地方，主持人会先追问。

创建世界

不必先写完一整本设定集。讲清你在意的几件事，其余空白会进表格，你可以再改。比较有用的信息是：

  • 这是什么样的地方，气氛如何
  • 有没有超凡。有的话，写来源、限制和代价；没有的话，直接说没有
  • 钱叫什么，大概能买到什么
  • 人怎么从一个地方到另一个地方，要多久，危不危险
  • 开场时玩家站在哪里

靠码头的石城，没有魔法。货币是铜贝，一枚铜贝买一顿简餐。城里走路，出城靠河船，上行要一整天，沿途有盗匪。

创建角色

说你是谁、为什么出现在开场、擅长什么。技能不必自己算完，说清经历之后，主持人会按规则填进表格。

退役的河船领航员，来找失踪的弟弟。水性好，认得出天气，不太会说话。

冒险进行中

  • 想问规则或商量计划，直接问。例如：这里的铜贝够不够住一晚？
  • 想让事情发生，用「我」写出具体行动。例如：我把船拴在栈桥上，先看布告板。
  • 遇到建议选项可以点，也可以自己写一句。
